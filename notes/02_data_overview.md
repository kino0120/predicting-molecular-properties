## Part 1. 基礎知識

### 1-1. スカラーカップリング定数（J）とは

**分子の中の2つの原子核が、間にある電子（化学結合）を介して互いに及ぼし合う磁気的な相互作用の強さ**。記号は **J**、単位は **Hz**。

- **原子核は小さな磁石**: H や ¹³C、¹⁵N の原子核は「スピン」を持ち、小さな磁石のように振る舞う
- **相互作用は電子経由**: 核Aのスピンが周りの電子をわずかに偏らせ、その偏りが結合の電子を伝わって核Bに届く。空間を直接伝わるのではなく、**結合の電子を通る**
- **NMR で観測される**: NMR（MRI と同じ原理の分析装置）では、この相互作用でピークが2本・3本…に分かれる。その分かれ幅が J。化学者は J から「どの原子とどの原子が何本の結合でつながっているか」「分子がどんな形か」を推定する
- **予測する理由**: J は量子化学計算（DFT）で正確に求められるが計算が重い。そこで「3D 構造から ML で一瞬で予測したい」というのがこのコンペの目的
- J は物理的な仕組みごとに **fc + sd + pso + dso** の4成分に分けられ、ほとんどの場合 **fc（フェルミ接触項）が大部分**を占める
- このデータの J は実験値ではなく **DFT による計算値**。教科書の実験値とは絶対値がずれる（例: 教科書だと sp³ の 1JCH は約 125 Hz、このデータの中央値は 87 Hz）。予測対象は「このデータの値」なので気にしなくてよい

### 1-2. "1JHC" の読み方

記法は **ⁿJ_XY**:

| 部分 | 意味 |
|---|---|
| 先頭の数字 **n**（1, 2, 3） | 2つの原子の間にある**結合の本数** |
| **J** | カップリング定数 |
| **XY**（HC, HH, HN） | 対象の原子ペア（片方は必ず H） |

```
1JHC:  H─C            (直結)
2JHC:  H─C─C          (1つの原子をはさむ)
3JHC:  H─C─C─C        (2つの原子をはさむ)
2JHH:  H─C─H
3JHH:  H─C─C─H
```

8種類: 1JHC, 1JHN, 2JHC, 2JHH, 2JHN, 3JHC, 3JHH, 3JHN。結合の本数が増えるほど相互作用は弱くなる（1JHC の平均は約 95 Hz、3JHC は約 3.7 Hz）。

#### ⚠ 2J の「2」は二重結合の意味ではない
「2」は**間にある結合の本数**で、結合が単結合か二重結合かとは関係ない。二重結合も経路の中では「1本」と数える。

```
アセトアルデヒド  CH3─CH=O  の場合

H6─C1        → 1JHC（1本で直結）。C1 は O と二重結合しているが、H6─C1 自体は1本
H6─C1─C0     → 2JHC（2本たどる）
H3─C0─C1─H6  → 3JHH（3本たどる）

エチレン H─C=C─H の H と H → 二重結合をはさんでいても 3JHH
```

### 1-3. 値を決めるのは分子の形

| 種類 | 主に何で決まるか |
|---|---|
| **1J** | C の**混成状態（結合の仕方）**。単結合だけの C < 二重結合の C < 三重結合の C |
| **2J** | H─C─X の**結合角** |
| **3J** | H─C─C─H の**二面角（ねじれ角）**。Karplus の式（cos² 型）で、0° や 180° のとき大きく、90° 付近で小さい |

手元の train.csv の 1JHC を、C が何個の原子と結合しているかで分けた結果（先頭15万件、結合は原子間距離から簡易判定）:

| C の状態 | 例 | 件数 | 中央値 |
|---|---|---:|---:|
| 4つと結合（sp³） | C─C 単結合だけ | 127,111 | 87.4 Hz |
| 3つと結合（sp²） | C=C / C=O 二重結合あり | 20,501 | 128.9 Hz |
| 2つと結合（sp） | C≡C 三重結合あり | 2,388 | 196.6 Hz |

→ 1位チームが 1JHC を C の結合数でサブタイプに分けたのはこのため。

読み取れること:
1. **C の結合の仕方で大きく変わる**: 単結合だけの C は約 77〜95、二重結合の C は約 110〜130、三重結合の C は約 170〜200 Hz
2. **隣の原子でも少し変わる**: 隣に O がある、3員環で歪んでいる（112.7）など
3. **同じ CH₃ の H でも値が違う**（プロパンで 83.5 と 80.7）: 分子の残りの部分に対する H の向きが違うため。3D 座標を見ないと区別できない

→ 1JHC は「どんな種類の C に付いた H か」で大枠が決まり、「周りの原子と 3D の向き」で細かく調整される。モデルにやらせたいのは、この細かい調整まで含めて当てること。

### 1-5. 二重結合はデータのどこにも書かれていない

データに**結合の情報は一切ない**。あるのは原子の種類と xyz 座標だけ。ただし**原子間の距離に二重結合が表れている**（手元のデータで実測）:

| 分子 | 原子ペア | 距離 | 結合 |
|---|---|---:|---|
| エタン | C─C | 1.530 Å | 単結合 |
| アセトアルデヒド | C─C | 1.508 Å | 単結合 |
| プロピン | C≡C | **1.201 Å** | 三重結合 |
| メタノール | C─O | 1.416 Å | 単結合 |
| アセトアルデヒド | C=O | **1.204 Å** | 二重結合 |

→ 結合が多重になるほど原子同士が近い。

**結合を復元する方法**:
1. **距離で「結合しているか」を判定**（原子半径の和より十分近ければ結合）
2. **価数のルールで結合次数を決める**（手の数: C=4, N=3, O=2, H=1）。例: アセトアルデヒドの C1 は H・C0・O の3つとしかつながっていないので手が1本余る → O との結合に回り C=O になる
3. **ツールに任せる**: RDKit（xyz2mol）や OpenBabel が座標から結合と結合次数を自動推定する。上位チームの多くが使用

**モデルへの渡し方（上位チームでは2通り）**:
- 1位・4位: ツールで結合や結合次数を推定し、明示的に特徴量として入れた
- 2位: 何も推定せず xyz だけを Transformer に入れ、モデル自身に学ばせた
- 最初は前者のほうが分かりやすく、効果も確実

### 5〜9. train 限定の「おまけ」データ

5つとも **train の 85,003 分子にだけあり、test の分子には1件もない**（確認済み）。モデルの入力には使えない。主な使い道:
- **補助ターゲット**: 「J と一緒にこれも当てさせる」ことで、モデルに化学的な表現を覚えさせる
- **中間予測**: まず電荷などを予測するモデルを作り、その予測値を特徴量に使う

1行 = 1分子のスカラー（85,003 行、単位はおそらくハートリー）。8と9は分子単位の値で、ペア単位の J との関係は薄い。上位チームでも有効に使った例はほとんどない。

## Part 3. モデルを作るうえで押さえておくべき点

1. **入力に使えるのは「原子の種類 + 座標 + どのペアか + type」だけ**。結合、二重結合、角度、二面角などはすべて座標から自分で計算する
2. **おまけデータは test にない**ので、入力ではなく補助ターゲットか中間予測として使う
3. **CV は分子単位で分ける**（train と test は分子で完全に分かれている）
4. **type ごとに物理が違う** → type ごと（できればサブタイプごと）に出力を分けるのが自然
5. **メモリに注意**: 主要な CSV だけで約 700MB、Mac のメモリは 8GB。pandas で読むときは float32 にする、使う列だけ読む、parquet に変換する、などの工夫が要る
